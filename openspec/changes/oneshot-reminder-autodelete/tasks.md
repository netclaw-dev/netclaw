## 0. Test-first state

The tests exist before the product code. They compile on `dev` and fail on `dev`, each for the behavior it names. Each task below makes the listed tests pass. Test classes are in `src/Netclaw.Actors.Tests/Reminders/` unless a path says otherwise.

- `OneShotReminderTestBase` is the shared harness. It runs the real manager on `TestScheduler` and `FakeTimeProvider`. Tests observe the tombstone as a JSON file (`ended/{escapedId}.json`, field names in design D1) and the durable Akka.Reminders state.
- `Netclaw.Tests.Utilities/ReminderEndedProtocol.cs` reads and builds the new protocol members (design D7) by reflection, so the test projects compile before the members exist. After the implementation, an implementer MAY replace it with the real types.
- Existing tests that state the old behavior stay green on `dev` and become wrong with this change. The implementation deletes or rewrites them, task by task: `Cancel_existing_reminder_disables_and_preserves_definition`, `Expired_reminder_disabled_on_fire_without_executing` (keep the recurring case), `Successful_oneshot_keeps_its_definition_and_history_for_the_retention_period`, `Channel_failure_retries_and_fifth_failure_disables_reminder`, `Reconcile_retains_a_delivered_oneshot_whose_completion_was_not_saved`, `Only_completed_oneshots_past_the_retention_period_are_pruned_with_their_history`, `Reconcile_prunes_stale_completed_oneshots_but_never_old_failed_reminders`, `Reconcile_retains_recent_terminal_oneshots_and_ambiguous_oneshots`, `Completed_oneshot_id_can_be_created_again_with_a_fresh_history_but_a_failed_one_cannot`, `Failing_oneshot_ends_failed_and_is_never_pruned`, `A_denied_one_shot_runs_once_and_is_kept_as_denied`, `A_denied_one_shot_is_not_counted_as_failed_and_is_never_pruned`.
