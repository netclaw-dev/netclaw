Scope

ShellSyntaxTree owns syntax and value facts. Netclaw owns grants, paths, consent, and launch authority.

  • Explain legacy grant near misses through the matcher's existing command identity.
  • Use exact effective Bash assignment values only after complete source and effect proof.
  • Preserve the assignment shell, names, scopes, environment effects, values, and existing digest format.
  • Bind shell Once consent to the original structured command, including recovered calls.
  • Check each supported outer compound redirect through existing file and launch authority.

The change adds no executable-specific grammar, grant scope, or durable approval field.

Requirements: PRD-002 SEC-003, SEC-006, SEC-007, SEC-009 and PRD-006.

Authority flow

This schematic omits normal actor and persistence steps. All admission and authority gates remain required.

admit the tool and audience
  -> analyze exact source with the existing launch snapshot
  -> screen hard deny, protected paths, roots, links, and file modes
  -> check each command candidate and independent file operation
  -> request exact Once consent or an assignment-qualified grant
  -> reparse and compare path and link state before launch

A matching file grant covers only its file operation. A command grant covers no outer redirect.

An unqualified command grant covers no assignment-qualified candidate. A changed effective value needs separate authority.

X=$HOME inspect item
X=/home/test inspect item

These synthetic examples can share an assignment identity only when the launch snapshot proves the same exact effective value.

Unknown facts retain exact consent or denial. PowerShell keeps its authored-value requirement.

Known limits

  • File-read body values can remain unknown. Parser support alone does not measure prompt reduction.
  • Supported compound owners with unknown or incomplete targets are denied before consent.
  • Unsupported outer target substitutions retain the existing unresolved-source policy.
  • A known baseline prohibition gap can hide a nested denied command in that unsupported source.
  • The existing glob-in-directory-segment catalog failure remains visible.
  • The historical corpus uses synthetic grants. It does not replay a production approval store.

The integration preserves the live daemon and saved approvals. A pull request does not deploy the local service.
