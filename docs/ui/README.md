# Netclaw UI Mockups

This directory contains management UI planning artifacts for Netclaw.

## Files

- `UI-001-ops-console-mockup.md` - page architecture, wireframes, and
  component behavior
- `TUI-001-command-wireframes.md` - Termina TUI wireframes for `netclaw init`,
  `netclaw chat`, and plain CLI commands
- `chat-reply-stack-v2/index.html` - interactive Netclaw chat hierarchy,
  state, motion, and responsive mock-ups
- `ops-console-v1.html` - static high-fidelity mockup for visual direction

## Design Intent

- operations-first, dense, and legible
- clear system status hierarchy
- security posture always visible
- fast drill-down from summary to root cause
