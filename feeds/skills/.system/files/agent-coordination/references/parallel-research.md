# Parallel Research

Use this workflow for distinct questions that benefit from independent source evidence.
Follow the common scope, authority, workspace, cancellation, and delivery rules in the base skill.

1. Divide the objective into distinct questions with useful independent scope.
2. Select available profiles whose current missions fit each question.
3. Assign source boundaries, revisions, acceptance checks, and separate report paths.
4. Permit shared read-only source inputs. Keep all source edits outside these research tasks.
5. Require evidence IDs, source citations, explicit uncertainty, and a direct answer to each assigned question.
6. Start the independent tasks and continue useful parent work.
7. Read each terminal result and its complete evidence report.
8. Compare the sources, assumptions, revisions, and contradictions.
9. Resolve disagreements from evidence. Record unresolved conflicts instead of a majority vote.
10. Produce a combined answer or reviewed artifact and deliver it through normal parent tools.

Do not duplicate broad questions merely to obtain model agreement.
Agreement between model outputs is not an independent fact check.
If a source is unavailable, record the gap instead of an inferred citation.

Positive example: one child checks runtime behavior and another checks the relevant protocol contract.
Negative example: three children repeat one unsupported claim, and the parent accepts their vote as proof.
