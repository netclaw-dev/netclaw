One unit of comprehension

The Reply Stack owns all model work for one Turn.

  • Tools do not become transcript speakers.
  • Parallel calls remain child rows.
  • The approval stays under its requesting tool.
  • The final receipt replaces transient work rows.

Named region map

Session StripIdentity and connection context. TranscriptImmutable terminal scrollback. Prompt SurfaceOne user message. Reply StackOne complete Netclaw reply. Reply PassageOne model step with its prose and work. Work TraceTransient tools and sub-agents. Decision SheetApproval context and choices. Queue ShelfPrompts that wait for the next Turn. ComposerPersistent message input. Pulse LineWait state and valid keys.

Chronology contract

The Reply Stack keeps the order that the operator experienced.

  • A completed call remains as a receipt while later calls run.
  • New model prose starts a new Reply Passage in the same Turn.
  • The next Work Trace follows the prose that explains that work.
  • Parallel calls share one group and retain separate states.
  • The settled Turn replaces all transient rows with one receipt.

  • Completed tools reuse the Human color.
  • Errors use Danger only when the result affects meaning.
  • All metadata uses one Muted color.
  • Each state shows at most three emphasis colors.

Fragment budget

  • One Prompt Surface per user message.
  • One Reply Stack per user Turn.
  • One Reply Passage per model step.
  • One Work Trace per passage that uses tools.
  • One Composer or one Decision Sheet. Never both.
  • No event-level cards in settled scrollback.

Turn transition

1
The user prompt opens one Reply Stack.
2
The Pulse Line starts before the first model delta.
3
Prose and Work Trace rows update inside that Reply Stack.
4
A Decision Sheet can pause one tool and own input.
5
The Turn freezes as one block. The queue promotes the next prompt.
